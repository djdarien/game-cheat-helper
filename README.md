# Game Cheat Helper

Expert video game walkthrough and deal finder chatbot.

- Game-specific maps, guides, cheats, and walkthroughs
- AI-powered chat for stuck moments (with photo upload)
- Best deals from G2A, CDKeys, and more
- Supports Xbox, PlayStation, Switch, PC

## Live Site

Deployed at [gamecheat.goodvibez.life](https://gamecheat.goodvibez.life)

## Features

- Enter any game (e.g. GTA 6) for tailored content
- Interactive links to maps, video guides
- Price comparison table for lowest deals
- Chat interface for questions + screenshot analysis

## Local Development

Open `index.html` in a browser or serve statically.

## Deploy

Push to Vercel/Netlify and set CNAME to gamecheat.goodvibez.life
