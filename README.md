# Game Cheat Helper

Expert video game walkthrough and deal finder chatbot. PWA-enabled for easy mobile/desktop install.

- Game-specific maps, guides, cheats, and walkthroughs (expanded library)
- AI-powered chat (xAI/Grok API key optional for real responses + photo support)
- Best deals from G2A, CDKeys, Instant Gaming, and more
- Supports Xbox, PlayStation, Switch, PC
- Progressive Web App: installable, offline-capable

## Live Site

Deployed at [gamecheat.goodvibez.life](https://gamecheat.goodvibez.life)

## Features

- Enter any game (e.g. GTA 6, Elden Ring, Fortnite, Minecraft) for tailored content
- Interactive links to maps, video guides
- Price comparison table for lowest deals
- Chat interface for questions + screenshot analysis
- PWA install prompt on supported browsers

## Local Development

Open `index.html` in a browser or serve statically. Register the service worker for PWA testing.

## Deploy

Push to Vercel/Netlify/GitHub Pages and set CNAME to gamecheat.goodvibez.life. Add icons to the repo for a polished PWA.

## AI Backend

Click the 🔑 API button in chat and paste your xAI API key (from x.ai). It is stored only in your browser's localStorage.
