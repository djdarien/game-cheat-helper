# Game Cheat Helper

PWA-enabled game guide chatbot with maps, cheats, deals, and AI chat.

**Live target:** gamecheat.goodvibez.life

## Features
- Game-specific maps, guides, cheats
- Best deal finder (G2A, CDKeys, Instant Gaming, Steam)
- Optional xAI/Grok real AI chat
- Recent games history
- Installable PWA (mobile + desktop)
- Screenshot upload for stuck moments

## Deploy
Enable GitHub Pages on main branch or deploy to Vercel/Netlify. Point CNAME to gamecheat.goodvibez.life.
